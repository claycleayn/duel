# 极简决斗

## 双设备 / 双页面

```bash
cd ~/projects/duel
node server.js
```

终端会打印本机和局域网的地址。打开页面:

- 电脑:`http://localhost:3000/?seat=0&cpu=0&rules=full`(玩家 1)
- 其他玩家:`?seat=1`、`?seat=2`、`?seat=3`(最多 4 人)
- 手机:把 `localhost` 换成启动时打印的局域网 IP(WireGuard 下通常是 `10.77.0.2`),按座位打开

房主（P1，`seat=0`，右上角会标「房主」）在页面顶部选人数 2/3/4。3-4 人时每回合所有人同时结算,攻击/黑暗要点其他玩家的卡片选目标,血量归零的玩家出局,最后存活者获胜。超过人数的页面是观众。端口被占用时用 `PORT=3001 node server.js`。

手机连不上时,确认手机能访问电脑的地址,并且防火墙放行对应端口。

## 人机对战

顶部「座位」按钮可以把 P2–P4 设为电脑（显示「2 机」等，切换会重开）；P1/`seat=0` 固定是房主，不能设成电脑。电脑之间会互相攻击；4 人时可选 2v2，电脑只打敌方。房主才能切换；其他人只读。

也可以直接用 URL，例如 4 人 2v2（P1 人类 + P2/P3/P4 电脑，P2 是队友）：

`http://localhost:3000/?seat=0&players=4&bots=1,2,3&teams=2v2`

`bots` 是电脑座位下标（逗号分隔），`teams=2v2` 只在 4 人时生效。`?cpu=1` 仍可快速开 1v1 人机（P2 电脑）。电脑每回合自动选招；你仍然只看到它的“已锁定”，结算时才亮牌。真人全部倒下后，剩下的电脑会自动继续结算，直到分出胜负或到 200 回合上限。电脑按护盾/血量/能量选目标，分数相同就各自随机，不会固定针对 P1。所有敌人 0 EN 时电脑不会防御/逃脱，改成蓄力或进攻。所有敌人 0 EN 时电脑不会防御/逃脱，改成蓄力或进攻。

## 规则

页面顶部可切「极简 / 完整」，只有房主（P1/`seat=0`）能切，切换会重开当前局。

### 极简

- 蓄力 +1 EN；防御：本回合受击 −1（一次）；攻击：−1 EN 造成 1；大招：−5 EN 造成 2
- 所有人同时选招、同时结算；互相攻击的双方逐点抵消
- 汇总每个玩家的受击值，减去防御值，得到扣血值；血量归零即败

### 完整

- 每人开局 1 层特殊护盾：第一次会掉血时消耗，免疫该回合剩余伤害；蓄力不刷新
- 8 技能：蓄力、攻击、防御、双斩（4 费 2 伤）、水枪（3 费 1 伤，穿透）、光明（4 费，成功转移才付 4 费，没转移任何伤害只付 1 费）、黑暗（5 费，成功转移才付 5 费，没转移任何伤害只付 1 费）、逃脱（1 费，免疫本回合所有普通伤害）
- 水枪的穿透只无视光明/黑暗与逃脱；防御和特殊护盾仍然有效
- 光明/黑暗都是转移（你不掉血），只转移普通伤害；穿透伤害不转移
- 血量归零即败；攻击/黑暗点其他玩家卡片选目标；3-4 人最后存活者获胜

## 卡牌

顶部「版本 → 卡牌」打开(或 URL `rules=cards`)。规则:

- 开局 100 点血量、30 点能量;能量不清空,每回合自动 +20
- 每回合抽 2 张基础 + 3 张其它牌,手牌保密;出牌张数不限,按提交顺序逐张扣费,回合结束弃掉全部手牌重新抽
- 出牌按提交顺序逐张结算:前面的聚能当场回能,后面的牌可以用;哪张牌能量不够,那张不打出,并扣 10 血、中断后续出牌、清空能量
- 逃脱带「排斥」词条:不能与其他牌同时打出
- 基础:蓄力(20,下下回合 能量 30)、攻击(10,攻击 10)、防御(10,格挡 15)
- 稀有:连斩(40,攻击 10*2)、水枪(20,攻击 10 穿透,精准)、力量(20,活力 20)、恢复(30,恢复 10 + 格挡 10)
- 史诗:黑暗(50,转移给指定目标,破绽)、光明(40,转移给攻击者,破绽)、逃脱(10,免疫普通伤害,排斥+破绽)、处决(50,伤害 20 + 敌人已损生命的一半)、聚能(30,能量 40)
- 词条(卡面黄色):格挡 X = 本回合获得 X 点格挡;攻击 X*N = 造成 X 点伤害 N 次;活力 X = 下一张攻击牌每段 +X;恢复 X = 回复 X 点生命;能量 X = 获得 X 点能量;破绽 = 被穿透攻击无视该效果但照付能量;精准 = 无视破绽效果并让对方照付能量
- 所有数值统一 ×10,方便按 1 点精度微调
- 结算仍走同一条管线:同时出牌 → 转移 → 各自汇总受击值减格挡(卡牌模式不互相抵消,双方伤害都生效)
- 力量按出牌顺序吃在下一张攻击牌上;没打攻击牌就留到下回合

## 多人

房主在顶部「人数」选 3 或 4，4 人时可选「队伍」混战 / 2v2。攻击、双斩、水枪、黑暗都要点其他玩家的卡片选目标；每回合所有人同时结算；血量归零的玩家出局并转为观战。

- 混战：最后存活者获胜。
- 2v2：固定 0/1 对 2/3；可以攻击队友（友伤），但胜利条件是消灭所有敌人。队友先倒下不影响，剩下的队员杀光敌方即可赢；双方全灭算平局。

## 文件

- `index.html` / `app.js` / `style.css` — 双屏客户端
- `engine.js` — 共享结算引擎(浏览器与 Node 共用)
- `bot.js` — CPU 对手策略
- `server.js` — HTTP + SSE 同步服务,无第三方依赖
- `hotseat.html` — 旧版单文件热座

## 公网部署（可选）

单房间:

```bash
ACCESS_TOKEN=<随机串> PORT=34871 node server.js
```

多房间（同一端口，按 token 隔离）:

```bash
ACCESS_TOKENS=<token1>,<token2> PORT=34871 node server.js
```

链接形如 `http://<公网IP>:34871/?room=<token>&seat=0&cpu=0&rules=full`（`seat=1/2/3` 给其他玩家，最多 4 人）。每个 token 是一个独立房间，房间之间互不影响。人机/队伍用页面顶部切换（房主可切），或 URL：`bots=1,2,3`（电脑座位）、`teams=2v2`（4 人时才生效）；人数用 `players=3/4`；版本用 `rules=minimal` / `rules=full`。建议用 systemd user 服务常驻，并在云安全组和主机防火墙放行该端口。不带 `room`（且没有开放房间）的页面和 API 请求会被拒绝。
